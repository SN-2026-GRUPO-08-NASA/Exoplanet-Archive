# Reflexão sobre o uso de IA

A IA ajudou a organizar o esqueleto do projeto e a transformar os requisitos em arquivos verificáveis. O grupo revisou as decisões mais sensíveis: a chave única do banco, a separação entre chave pública e service role, RLS e o tratamento de dados externos no painel. A principal limitação foi que a IA não tem acesso às credenciais nem substitui testes com dados reais. Por isso, a validação final exige execução do workflow, inspeção das tabelas e teste do GitHub Pages pelo grupo.
